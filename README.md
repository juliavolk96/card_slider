# The Apothecary Diaries - Characters Slider

A responsive character profile slider based on "The Apothecary Diaries" anime. This project focuses on clean UI/UX and modern CSS practices.

## Live Demo
Check out the project here: [https://juliavolk96.github.io/card_slider/](https://juliavolk96.github.io/card_slider//)

## Tech Stack
* HTML (Semantic Markup)
* CSS (Custom Properties, Flexbox)
* JavaScript (ES6+)
* Swiper JS (Slider functionality)

## Key Features
* **Adaptive Height**: All cards maintain a uniform height regardless of content length, ensuring a consistent grid layout.
* **Interactive Tooltips**: Hover-activated tooltips display full character descriptions without causing layout shifts.
* **Semantic Navigation**: Modern link-based buttons for improved SEO and accessibility.
* **Fully Responsive**: Optimized for desktop, tablet, and mobile screens.

## Installation
1. Clone the repository.
2. Open `index.html` in your preferred web browser.
